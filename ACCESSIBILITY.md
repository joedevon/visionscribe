# Accessibility

VisionScribe exists so that people who can't see an image still get what it says. Screen reader users, people with low vision, and anyone whose images fail to load depend on alt text and image descriptions. When those are missing or vague, they lose information everyone else gets. Accessibility is the whole purpose of this project, so it applies to what VisionScribe writes and to its documentation.

## What we aim for

- **Useful output.** Alt text and descriptions should convey an image's purpose in context, following the advice of accessibility experts, WCAG and the W3C alt text decision tree, rather than listing what is visible.
- **Accessible documentation.** The README and this file should work with assistive technology, with real headings, descriptive link text, and text alternatives for any images.

VisionScribe drafts alt text. It does not make a page accessible or compliant on its own. A person who knows where the image will appear should review the result before publishing it.
