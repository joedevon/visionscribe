# Accessibility

VisionScribe drafts descriptions for people who cannot see an image or whose images fail to load. The descriptions should explain what the image contributes to the page.

## What we aim for

- Alt text and descriptions should explain the image's purpose in context. The guidance draws on WCAG, the W3C Alt Text Decision Tree, and how people use screen readers.
- Documentation should use headings, descriptive links, and text alternatives for images so people can read it with assistive technology.

VisionScribe does not make a page accessible or compliant on its own. Someone who knows where the image will appear should review the description before publishing it.
